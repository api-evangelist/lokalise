# Lokalise GraphQL API

Lokalise is a translation management platform for apps and websites. The API covers project and key management, file uploads, translation creation, screenshot context, order management, task management, and webhook integration.

**Endpoint:** No native GraphQL endpoint — conceptual schema derived from Lokalise REST API
**Documentation:** https://developers.lokalise.com/

- Reference: https://developers.lokalise.com/reference/api-overview
- Schema: https://github.com/api-evangelist/lokalise
